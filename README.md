### 一、项目简介与命题背景

本项目专为**马来西亚华文独立中学（MICSS）高中统考（UEC）厨艺科（烘焙理论）**量身打造，涵盖高一全年度 **20 门核心必修课程**，共计精编 **800 道专业选择题**，并配有完整的交互式答题平台与详尽的理化考点解析。

本题库严格按照统考教研标准，由自动化命题工程脚本与学术审校流水线深度清洗生成，彻底解决传统模拟卷中存在的“选项长度泄题”、“答案分布倾斜”、“难度脱节”等常见弊端。

### 二、题库质量标准与四大金科玉律

每一课的 40 题标准试题均严格通过自动化脚本校验，必须满足以下硬性指标：

| 规范维度 | 考核标准 | 质量保障方式 |
| :--- | :--- | :--- |
| **1. 难度梯度黄金配比** | 严格执行 **20 题容易 + 15 题中等 + 5 题较难**<br>• **容易**：生活常识、直观厨房操作、基础命名<br>• **中等**：工艺控制参数、理化变化机理、翻车诱因诊断<br>• **较难**：统考真题变式、逆向百分比换算、罗马数字组合题 | 运行 `work/check_difficulty.ps1` 逐课校验 |
| **2. 选项平行等长** | **彻底消除“长选法”投机**：A、B、C、D 四个选项字数控制在极近区间（字数差 $\le 4$ 字），无长度突变泄题。 | 运行 `work/analyze_lengths.ps1` 零偏倚拦截 |
| **3. ABCD 答案均等** | **完全绝对均衡**：每课 40 题中，**A、B、C、D 各占正好 10 题（各 25%）**，杜绝连选连续 3 题相同。 | 运行 `work/check_dist.ps1` 自动化核验 |
| **4. 深度解析全覆盖** | 每道题均配有 80~150 字的专业解析，涵盖原料特性、工艺核心与统考易错避坑要点。 | 题目数据源全面内置完整解释 |

### 五、本地运行与二次编译

1. **直接浏览器运行**：
   - 双击打开根目录的 [`index.html`](index.html) 或 [`高一厨艺理论_全套第01至20课_800题互动答题总系统.html`](高一厨艺理论_全套第01至20课_800题互动答题总系统.html)，即可离线自测，无需任何后端服务器。

2. **重新编译全套 800 题交互网页**：
   - 若在 `work/data/chapter*.json` 中修改了试题或解析，执行以下命令即可一键重新生成 `index.html` 与对应主交互网页：
     ```powershell
     powershell -ExecutionPolicy Bypass -File "work\compile_html_all_20.ps1"
     ```

3. **质量检测命令**：
   ```powershell
   # 校验全20课难度梯度
   powershell -ExecutionPolicy Bypass -File "work\check_difficulty.ps1"
   
   # 校验全20课ABCD分布
   powershell -ExecutionPolicy Bypass -File "work\check_dist.ps1"
   
   # 校验全20课选项长度差
   powershell -ExecutionPolicy Bypass -File "work\analyze_lengths.ps1"
   ```
